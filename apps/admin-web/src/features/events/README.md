# Event console (GAP-03, D07, S09)

BRD v1.1 §11.11, §11.25, §15A.6; screens D07, S09; requirements FR-EVT-001 to 017, FR-ADM-004, FR-STF-006.

**Status: Built.**

Staff console for managing events:
- Paginated, area-scoped event list with state filter (draft, published, cancelled)
- Creating draft events in staff assigned areas
- Scoped editing of event details (time, venue, capacity, accessibility)
- Publishing events with explicit confirmation
- Attendance inspection and audited, spreadsheet-safe CSV roster export
- Event cancellation with mandatory audited reason and member SMS alerts
