# Member-app components

`GalleryImage.tsx` (a gallery photo through the API) and `QueryView.tsx` (the shared loading view with this app's error words). `FeatureQueryView.tsx` adds the calm "not open yet" for a Phase 2 module that is switched off; `ReceiptCard.tsx` (a server receipt with its reference), `DetailRow.tsx`, `ProgressBar.tsx`, `ToggleChips.tsx` (multi-choice chips), `Collapsible.tsx` (a heading that opens long text) and `FieldError.tsx` are shared by the volunteering, ideas, proposals, surveys, learning and invitation screens. The components the staff app also uses (`AppText`, `Screen`, `Button`, `TextField` and the rest) moved to `packages/mobile-ui` in Batch 23.

BRD v1.1: BR-087 (status never by colour alone), BR-088 (honest empty states); NFR accessibility (WCAG 2.2 AA).
