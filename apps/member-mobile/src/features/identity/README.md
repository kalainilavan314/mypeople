# Identity documents, review and appeal

Capturing and uploading identity images, submitting for review, showing the review state, corrections and the appeal. Images are held only in app-private storage until the server acknowledges them (FR-REG-035, BR-021).

**Status: not built yet.** API: `/v1/identity/me/documents`, `/v1/identity/me/review`, `/v1/identity/me/review/appeal` and `/v1/identity/me/evidence-views` exist (`services/api/app/modules/identity`).

BRD v1.1: FR-REG-001 to 036, FR-IDV-001 to 017; screens A03 to A17, M01 to M05.
