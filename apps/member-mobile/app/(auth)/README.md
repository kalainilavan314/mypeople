# Sign-in, registration and identity verification screens

Expo Router screens shown before the member is signed in: `sign-in.tsx` (A02), `register.tsx` (A03) and `verify-identity.tsx` (A04 to A09: route, consent, NIC or passport images, selfie, review and submit).

**Status: not built yet.** The API they will call exists: `/v1/auth/sign-in`, `/v1/identity/me/documents`, `/v1/identity/me/review` and `/v1/identity/me/review/appeal`.
