# My People logo

The logo's source files are Puvi's redrawn brand assets in `apps/member-mobile/assets/brand` (13 November 2026). They replaced the older 512-pixel logo, which had been cut out of a white background and kept a pale rim. The files there:

| File | What it is |
|---|---|
| `app-icon.png` | 1024 × 1024, on the page colour `#fffbf5`: the app icon |
| `adaptive-icon.png` | 1024 × 1024, transparent, the logo inside Android's safe zone (the largest transparent logo, 557 px) |
| `logo.png` | 500 × 500, transparent: the logo on screens (welcome card, top bar, Home, Profile) |
| `splash-logo.png` | 512 × 512, transparent: the splash screen |
| `favicon.png` | 64 × 64: the browser tab icon |

The files in this folder are made from them, for documents and for anyone who needs the logo without opening the app:

| File | Use |
|---|---|
| `my-people-logo-transparent.png` | 600 × 600, transparent: coloured backgrounds and photos |
| `my-people-logo-white.png` | 640 × 640, the logo on white with a margin: documents and solid backgrounds |
| `my-people-app-icon.png` | A copy of the 1024 × 1024 app icon |

The member PWA (`app/public/logo.png`, `favicon.png`, `icons/icon-192.png`, `icon-512.png`, `icon-512-maskable.png`) and the dashboard's tab icon (`apps/admin-web/src/app/icon.png`) are made from the same assets.

Print and large banners need the designer's original vector artwork; ask for it rather than enlarging these files.
